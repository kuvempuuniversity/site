# Department header photographs

Recommended image size: 1600 x 1200 pixels (4:3), saved as a genuine PNG.

Use these exact paths:
- assets/img/departments/environmental-science-header.png
- assets/img/departments/applied-botany-header.png

PNG placeholders are supplied separately for upload. They are not embedded in this text-file commit. Upload them from the supplied ZIP, or upload the real images directly using the exact filenames above. Once deployed, replacing an image with the same name needs no code change.

The existing department landing layout is unchanged. Its first image uses object-fit: cover, so cropping can differ between desktop and mobile. Keep the principal subject near the centre and avoid embedded text or important details at the edges. The nominal mobile frame is 4:3; desktop height follows the adjacent introduction.

Until a dedicated PNG loads, the page falls back to its previous illustrative image. Other research and facilities images are not changed by this configuration.
